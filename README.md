# Alpha Sentinel — Clear Communication (Mobile) preview

Standalone HTML preview for phone testing. `index.html` is `builds/clear-communication-mobile.html` from the main workspace, unchanged.
Sample data, simulated payment and verification, not a live website.

Publish with GitHub Pages: Settings → Pages → Source "Deploy from a branch" → branch `main`, folder `/ (root)`.

Second page: `app-brand.html` is `builds/clear-communication-app-brand.html` — the same preview in the member app's own look
(parchment ground, mono labels, chip pills). Open it at `/alphasentinel/app-brand.html`.
